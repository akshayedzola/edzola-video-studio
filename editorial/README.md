# Editorial

Cross-episode editorial material. Per-episode work lives in `episodes/<id>/`.

| Folder | Purpose |
|---|---|
| `briefs/` | Episode ideas not yet started (one `.md` each, using `episodes/_template/brief.md`), plus `ideas-backlog.md` |
| `scripts/` | Long-form script drafts before they're split into storyboard beats (optional) |
| `storyboards/` | Reusable storyboard fragments, e.g. a standard Sitara Foundation intro scene |
| `source-references/` | Reading notes on external sources (third-party sector research) with links and licence notes |

Start a new idea in `briefs/`. When a human approves it, move it to `episodes/<id>/brief.md`.
