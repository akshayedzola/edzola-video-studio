# Brief: What is an MIS, really?

| Field | |
|---|---|
| Episode id | a001-what-is-an-mis (reference episode) |
| Series | A: Technology for Impact, Explained |
| Audience | Nonprofit programme leaders and M&E heads who have bought software but still fight over report numbers |
| The problem they feel | "Every quarterly report starts an argument about whose number is right." |
| Central argument | An MIS is one record per person, shared by everyone, that the work runs through. |
| Learning outcome | The viewer can explain *how* separate team records produce conflicting reports, and name the five layers of an MIS that prevent it |
| Misconception dismantled | "Someone made an error", and "an MIS is software / a dashboard / a bigger spreadsheet" |
| Analogy | A hospital where doctor, nurse and pharmacist keep three files on one patient |
| Twist | None of the three numbers was right: each team counted correctly, but they counted different things |
| Practical takeaway | Three questions to ask your team on Monday |
