# Sitara Foundation: our recurring fictional organisation

**Status:** illustrative. Sitara Foundation does not exist. Every name and number about it is invented. Always show the "Illustrative data" tag on screen when its data appears.

Using one fictional organisation across episodes lets viewers build familiarity, and it lets us show realistic mess without exposing any partner.

## Series bible (keep consistent across episodes)

| Attribute | Value |
|---|---|
| Sector | Youth skilling and livelihoods, India |
| Size | 500 learners per year, ~25 staff, 3 training centres |
| Lifecycle | Mobilisation → Enrolment → Training → Placement → Retention (90-day follow-up) |
| Teams | Programme (runs batches), Finance (stipends, grants), M&E (outcomes, funder reports) |
| Starting state (S1) | Three spreadsheets, WhatsApp groups, a dashboard nobody trusts |
| Funder pressure | Quarterly placement numbers; a new funder asks for 6-month retention |
| Arc across Season 1 | ep000: discovers fragmentation → later episodes: models its data (MAP: Model), changes workflows (Align), tries AI voice follow-ups (Power) |
