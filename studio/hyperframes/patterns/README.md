# Scene patterns

Reusable HyperFrames scenes extracted from published episodes. Copy one into `episodes/<id>/scenes/`, keep its structure, change content and timing.

| Pattern | Formula move | Reference |
|---|---|---|
| CaseOpen | 1 Cold open | `episodes/a001-what-is-an-mis/scenes/cold-open.html` |
| Analogy | 2 Analogy | `…/scenes/hospital.html` |
| QuarterSim | 3 Watch it happen | `…/scenes/quarter-sim.html` |
| Predict | 4 Predict | `…/scenes/predict.html` |
| Collapse | 5 Twist | `…/scenes/twist.html` |
| LayerStack | 6 Build the answer | `…/scenes/build-mis.html` |
| SplitReplay | 7 Replay | `…/scenes/replay.html` |
| NotList | 8 What it's not + Monday questions | `…/scenes/not-list.html` |
| Close | 9 Close | `…/scenes/close.html` |

**Contributing a pattern:** generalise a scene so its content comes from a clearly marked `CONTENT` block at the top of the script, add it here with a one-line description, and link the episode it came from.
